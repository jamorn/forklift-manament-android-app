# 🧹 Ktlint Setup + วิธีใช้ `ktlintFormat`

> คำอธิบายการติดตั้ง Ktlint ลงโปรเจกต์ และการจัดรูปแบบ code ด้วย `ktlintFormat`

---

## 📌 Ktlint คืออะไร

**Ktlint** เป็นเครื่องมือ **Linter + Formatter** สำหรับภาษา **Kotlin**

- **Lint** → ตรวจหา code style ที่ไม่ตรงมาตรฐาน (indent, space, trailing comma, import order, ฯลฯ)
- **Format** → แก้ไขให้อัตโนมัติ (auto-correct) หลายจุด
- ใช้ plugin: **`org.jlleitschuh.gradle.ktlint`** version `14.2.0`

> เหมาะกับโปรเจกต์ Jetpack Compose ที่เขียนสไตล์ compact (parameter ยัดบรรทัดเดียว) → ktlint จะจัดให้เป็นระเบียบมาตรฐานเดียวทั้งโปรเจกต์

---

## ⚙️ 1. ติดตั้ง Ktlint ลงโปรเจกต์

### 1.1) `build.gradle.kts` — root (plugins ระดับ project)

```kotlin
plugins {
    id("com.android.application") version "8.2.2" apply false
    id("org.jetbrains.kotlin.android") version "1.9.22" apply false
    // ...
    id("org.jlleitschuh.gradle.ktlint") version "14.2.0" apply false  // ← เพิ่มบรรทัดนี้
}
```

### 1.2) `app/build.gradle.kts` — แอป (ประกาศใช้ plugin + ตั้งค่า)

```kotlin
plugins {
    // ...
    id("org.jlleitschuh.gradle.ktlint")   // ← เพิ่ม
}

ktlint {
    // ใช้ Android code style → 4-space indent ตรงกับ VSCode ที่ตั้งไว้
    android.set(true)

    // ระยะแรกยังไม่ทำให้ build ล้ม — ดูผล report ก่อน (ค่อยเข้มทีหลัง)
    ignoreFailures.set(true)

    // ไม่ให้ ktlint เข้าไปยุ่งกับไฟล์ autogenerated
    filter {
        exclude("**/generated/**")
    }
}
```

## 🗝️ 2. อธิบายตัวเลือก (config properties)

| Property | ค่า | ความหมาย |
|---------|------|---------|
| `android.set(true)` | `true` | ใช้ **Android code style** → **4-space indent** (ถ้า `false` จะเป็น 8-space แบบ Kotlin มาตรฐาน) |
| `ignoreFailures.set(true)` | `true` | **ไม่ทำให้ build ล้ม** เมื่อมี lint error — เหมาะกับช่วงแรก อยากเห็น report ก่อน |
| `filter.exclude(...)` | generated | ไม่ให้ ktlint แตะไฟล์ autogenerated |

### ⚠️ ข้อควรรู้: การ disable rule
- อยาก disable rule บางตัว (เช่น อนุญาต wildcard import / Composable PascalCase) ต้องส่งผ่าน editorconfig **โดยใช้ชื่อ property ที่มี prefix `ktlint_`** ตรงกับเวอร์ชัน plugin
- ถ้าใช้ชื่อผิดจะได้ error:
  ```
  Property with name 'ktlint_no_wildcard_imports' is not found in any of given rules
  ```
- **error จะปริ้นต์รายชื่อ rule ทั้งหมดที่ถูกต้องให้ดูเสมอ** → ให้ copy ชื่อจาก error นั้นไปใช้

## 🚀 3. คำสั่งที่ใช้งาน

### ✅ Check (ตรวจอย่างเดียว ไม่แก้)
```powershell
./gradlew :app:ktlintCheck
```
> ตรวจหา lint issue แล้วรายงาน ถ้า error + `ignoreFailures=true` → build ยังผ่าน แต่พอ `false` จะ `BUILD FAILED`

### ✍️ Format (แก้ให้อัตโนมัติ)
```powershell
./gradlew :app:ktlintFormat
```
> **autofix** ทั่วโปรเจกต์: indent, trailing comma, import order, space, semicolon, blank line...

### 🧹 ตรวจรวมทั้งโปรเจกต์ (formatter)
```powershell
./gradlew ktlintFormat
./gradlew ktlintCheck
```

## 🧾 5. ผลลัพธ์ที่ได้จาก `ktlintFormat` (ใน session นี้)

### ✅ auto-correct ได้ — หายเป็นระเบียบทั่วโปรเจกต์

| รายการที่แก้ | ตัวอย่าง |
|-------------|---------|
| **Indent** สม่ำเสมอ (4 space) | `buildFeatures { compose=true; buildConfig=true }` → แยกหลายบรรทัด |
| **Trailing comma** | `listOf(a, b,)` (เพิ่ม comma ท้ายใน multiline) |
| **Import order** | เรียงตามตัวอักษร |
| **Space** รอบ operator / หลัง `,` | ทำให้เหมือนกันทุกไฟล์ |
| **Semicolon** `;` | แยกให้คนละบรรทัด |
| **Blank line** | คงไว้ 1 บรรทัดว่างระหว่าง block |

### ⏸️ not auto-correct ได้ — เหลือ warning (build ยังผ่าน เพราะ `ignoreFailures=true`)

| รายการ | เหตุผลที่ต้องตั้งค่า rule หรือค่อยจัดการ |
|--------|----------------------------------------|
| **Composable ใช้ PascalCase** (`function-naming`) | Compose บังคับ composable ขึ้นด้วยตัวพิมพ์ใหญ่ — ขัดกับ rule เก่า ktlint |
| **Wildcard import** | โปรเจกต์ใช้ `import androidx.compose.*` เยอะ |
| **Package name มีตัวพิมพ์ใหญ่** (`CategorySection` ฯลฯ) | folder ชื่อ UpperCamelCase |
| **KDoc ซ้อน** (Extensions.kt) | minor — รอปรับทีหลัง |

> 💡 ถ้าอยากให้สะอาด 100% → ตั้ง `.editorconfig` ที่ root เพื่อ disabled rule ที่ขัดกับ Compose (ตามเอกสาร Ktlint .editorconfig)

## 🔎 6. เทคนิค: อ่าน error แล้วแก้ config ให้ถูก

ตัวอย่าง error ที่เจอตอนลองตั้ง rule ผิด:
```
Property with name 'ktlint_no_wildcard_imports' is not found in any of given rules.
Available properties:
    - end_of_line
    - ij_kotlin_im..._layout
    - ktlint_function_naming_ignore_when_annotated_with  ← ชื่อที่ถูกต้อง
    - ...
```

**วิธี:** ถ้า error แจ้งชื่อ rule ไม่เจอ → ให้ดู **"Available properties"** ใน error นั้น แล้ว **ใช้ชื่อที่ ktlint version นั้น รู้จักจริง**
